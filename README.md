# handtracker
Laser-Hand-Tracker Art Project

Inspired by my work with BepiColombo's BELA laser altimeter: From mapping Mercury's surface
one laser pulse at a time to tracing invisible geometries with our hands, the principle is
the same: light reveals structure.
